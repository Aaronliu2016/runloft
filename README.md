# RunLoft

**把本地 Web 项目作为桌面应用启动。**

RunLoft 计划提供一个桌面入口：从 Git 仓库获取 Web 项目，按项目声明的命令在本机启动服务，再在桌面窗口中显示它。目标项目继续使用自己的框架和运行时；RunLoft 管理仓库、进程生命周期和窗口。

> **项目状态：** 方案整理与技术验证阶段。当前仓库还没有可运行的应用或开发命令。

## 预期使用流程

1. 添加 Git 仓库并选择本地工作区。
2. 克隆仓库，或为已有的干净工作区获取更新。
3. 查看项目的 RunLoft 配置并授权其中的命令。
4. 按需安装依赖，然后启动项目。
5. 等待本地 HTTP 服务就绪，并在桌面窗口中打开。
6. 停止项目或退出 RunLoft 时，关闭由 RunLoft 管理的进程。

RunLoft 面向已经能在开发者电脑上运行的本地 Web 应用。它不会重写项目界面，也不会悄悄替换项目现有的构建和运行工具链。

## 技术方向

当前方向是使用 Go 和 [MyGo](https://github.com/egoist/mygo) 构建桌面窗口与系统 WebView，并由 Go 管理 Git 操作和子进程。进入正式实现前，需要先验证本地服务加载、导航限制和进程清理在首发操作系统上可用。
