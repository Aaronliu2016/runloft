## 当前已确认方向

- 项目暂定名为 **RunLoft**。
- 产品形态是 Go 桌面应用外壳；目标 Web 项目仍由其仓库提供的命令启动。
- 期望流程包括 Git 仓库获取、启动本地 Web 服务，以及在桌面窗口中显示该服务。
- MyGo 是当前桌面框架方向，需先通过真实项目的 WebView 和进程管理验证。
